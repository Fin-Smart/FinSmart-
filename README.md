# FinSmart Promo Website

Modern editorial tech landing page inspired by `promo.buszbee.com`.

Static site, no build step needed. Deploy as its own Vercel project (Framework Preset: Other).

- **Contact Email**: `oratile@finSmart.co.za`
- **Clean URLs**: Configured via `vercel.json` (`/support`, `/contact`, `/`)
- **Key Features**:
  - Masked kinetic hero typography with Inter & JetBrains Mono
  - Infinite activity ticker with hot-pink indicator pills
  - Interactive product simulator (Scam Check, Rand Budgeting, Smart Coach AI)
  - Interactive "What's Inside" feature rows with hover inversion
  - Kinetic scroll parallax typography band
  - Accordion FAQ with smooth expand/collapse
  - Giant brutalist wordmark footer
